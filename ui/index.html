Source, issues, and security reports: github.com/jonbng/network-cartographer

Privacy summary

  • Monitoring is local (OS socket tables + process metadata).
  • Optional online GeoIP may send IP addresses to third parties.
  • Use a local GeoLite2 MMDB (NETWORK_CARTOGRAPHER_MMDB) to reduce or avoid online GeoIP.
  • Free ip-api.com batch lookups use HTTP only (HTTPS is a paid plan).
